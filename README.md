# Olist E-Commerce Sales & Customer Experience Analysis

## Project Overview

This project analyzes Brazilian e-commerce data from Olist to understand sales performance, customer experience, payments, products, sellers, reviews, and delivery performance.

The project follows an end-to-end Data Analyst workflow using SQL, Python, and Power BI.

## Tools Used

- SQL Server
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI

## Dataset

The project uses the Olist Brazilian E-Commerce Public Dataset containing information about:

- Customers
- Orders
- Order Items
- Payments
- Reviews
- Products
- Sellers
- Geolocation
- Product Category Translation

## Analysis Performed

### SQL Server

- Data quality checks
- Revenue analysis
- Order analysis
- Average order value
- Monthly revenue
- Product category analysis
- Seller analysis
- Payment method analysis
- Review score analysis
- Delivery time analysis

### Python

Used Pandas and NumPy for data analysis and Matplotlib for visualization.

Analysis included:

- Product data quality
- Customer analysis
- Payment analysis
- Seller analysis
- Monthly revenue
- Review score distribution
- Delivery time analysis
- Delivery time vs review score

### Power BI

Created an interactive dashboard containing:

- Total Revenue
- Total Orders
- Average Order Value
- Total Customers
- Average Review Score
- Revenue by Year
- Revenue by Product Category
- Revenue by Payment Type
- Review Score Distribution
- Delivery Days by Review Score

## Key Findings

- Average delivery time was approximately 12.09 days.
- 1-star reviews had an average delivery time of about 20.85 days, compared with about 10.22 days for 5-star reviews.
- Longer delivery times were associated with lower review scores.
- The product dataset contained 610 missing product-category values.
- Sales performance was analyzed across monthly trends, product categories, sellers, and payment methods.

## Project Outcome

This project demonstrates an end-to-end Data Analyst workflow using SQL Server, Python, and Power BI to transform raw e-commerce data into meaningful business insights.
