# Olist E-Commerce Sales & Customer Experience Analysis

## Project Overview

This project analyzes Brazilian e-commerce data from Olist to understand sales performance, customer experience, payments, products, sellers, reviews, and delivery performance.

The project follows an end-to-end Data Analyst workflow using SQL, Python, and Power BI.

## Tools Used

- SQL Server
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI

## Dataset

The project uses the Olist Brazilian E-Commerce Public Dataset containing information about:

- Customers
- Orders
- Order Items
- Payments
- Reviews
- Products
- Sellers
- Geolocation
- Product Category Translation

## Analysis Performed

### SQL Server

- Checked missing values
- Checked duplicate records
- Checked invalid values
- Analyzed order status
- Calculated total revenue
- Calculated total orders
- Calculated average order value
- Analyzed monthly revenue
- Analyzed product categories
- Analyzed top sellers
- Analyzed payment methods
- Analyzed review scores
- Analyzed delivery time
- Compared delivery time with review scores

### Python

Used Pandas and NumPy for data analysis and Matplotlib for visualization.

Analysis included:

- Product data quality
- Product category analysis
- Customer analysis
- Payment analysis
- Seller analysis
- Monthly revenue
- Review score distribution
- Delivery time analysis
- Delivery time vs review score

### Power BI

Created an interactive dashboard containing:

- Total Revenue
- Total Orders
- Average Order Value
- Total Customers
- Average Review Score
- Revenue by Year
- Revenue by Product Category
- Revenue by Payment Type
- Review Score Distribution
- Delivery Days by Review Score

## Key Findings

- Total revenue shown in the Power BI dashboard was approximately 16.01M.
- The dashboard showed approximately 99K orders and 96K customers.
- Average order value was approximately 160.99.
- Average review score was approximately 4.09.
- Average delivery time for delivered orders was approximately 12.09 days.
- Orders with lower review scores had longer average delivery times. For example, 1-star reviews had an average delivery time of about 20.85 days, while 5-star reviews had an average of about 10.22 days.
- The product dataset contained 610 missing product-category values.

## Project Outcome

This project demonstrates the ability to work with raw transactional data, perform data cleaning and analysis using SQL and Python, create visualizations, and present business insights through a Power BI dashboard.
